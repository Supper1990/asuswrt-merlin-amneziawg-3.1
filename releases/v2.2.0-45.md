Исправлена потеря IPv4-маршрутизации по стране для входящих клиентов AmneziaWG после обновления аддона. В режиме **LAN + incoming VPN IPv4** пакет сам заполняет цепочки совместимого AWGS Manager при запуске и повторном применении firewall. Локальный патч после обновления больше не нужен.

Требуется серверный AWGS Manager с поддержкой цепочек `AWGSM_CM43` и `AWGSM_CF43` (маркер `AWGSM_COUNTRY43`). Менеджер по-прежнему определяет права отдельных клиентов. Пакет не изменяет manager.py. На роутерах без совместимого менеджера дополнительные цепочки не создаются. Правила IPsec и IPv6 не изменились.
