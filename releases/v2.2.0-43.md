В Routing Policy → Default Policy появился режим **LAN + incoming VPN IPv4: Russia via WAN, other + selected via VPN**. Сохранён отдельный режим только для LAN; обновление пакета само политику не переключает.

Для входящих клиентов на серверных интерфейсах AmneziaWG (awgs+), WireGuard (wgs+) и OpenVPN (tun2+, tap2+) действуют те же правила выбора IPv4-направлений, что и дома: российские сети используют обычную маршрутизацию, явно выбранные и остальные публичные сети — awg0. Существующие метки, индивидуальные правила и локальные назначения сохраняют приоритет. Ответы входящих VPN-соединений не классифицируются этим новым правилом.

Для IPsec укажите в Additional VPN clients `ipsec@ПУЛ` с фактическим пулом IPv4 клиентов. Для другого виртуального интерфейса укажите `интерфейс@ПУЛ`. Одного совпадения адреса источника недостаточно. Для полного охвата профиль телефона должен направлять интернет-трафик на домашний ASUS; для доменных списков используйте DNS роутера. База RU в обоих режимах обновляется ежедневно в 04:00 по времени роутера. IPv6 не классифицируется.
