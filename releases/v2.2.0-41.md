Исправлен откат Apply, если имя VPN-сервера разрешилось только в IPv6. Аддон берёт адрес действующего peer из `awg show awg0 endpoints` после setconf. Только числовой IPv4 используется для исключения в цепочке AWG и маршрута через IPv4-шлюз. При транспорте IPv6 эти две операции пропускаются, а IPv4-маршрутизация внутри туннеля остаётся включённой. При остановке удаляется только записанный аддоном маршрут.
