Новая политика для LAN IPv4: российские сети используют обычную маршрутизацию WAN, остальные публичные адреса и явно выбранные VPN-направления — awg0. Выбор страны определяется IP назначения. Индивидуальные правила устройств и предыдущие решения других аддонов сохраняют приоритет. Если МТС — основной WAN, трафик по обычному маршруту выходит через МТС. IPv6 не классифицируется этим режимом.

Для включения выберите **Routing Policy → Default Policy → LAN IPv4: Russia via WAN, other + selected via VPN**, затем **Apply**. База [RU GeoIP](https://raw.githubusercontent.com/Loyalsoldier/geoip/release/text/ru.txt) загружается при первом включении и автоматически обновляется ежедневно в **04:00 по времени роутера**, даже если auto-update общих геобаз выключен. Отдельное задание заменяет активный набор после проверки, не перезапуская туннель. Ошибка загрузки не стирает прежний список.
